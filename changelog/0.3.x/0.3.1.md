# 0.3.1 — 2026-11-21

## Added

- **`faa_delays_get_operations_plan`** returns optional `sentAt` in UTC from the cached FAA advisory. If the send time is unavailable, the plan remains available with a notice. ([#31](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/31))

## Changed

- **`faa-traffic-delays-guide`** explains how to read closure scope and date the operations plan.
- **Bun engine floor** rises from 1.4.0 to 1.4.4. Framework tooling and configuration examples are synced.

## Fixed

- **Airport-wide closure NOTAMs** in effect set airport status to `closed` and take closure rank in active events. They retain the `closureNotam` field and `closure_notam` event type. ([#30](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/30))
- **FAA-authored text** displays literal punctuation and preserves quoted line breaks in Markdown. Structured FAA text remains verbatim, and stored notices stay plain. ([#32](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/32))
- **Performance regression tests** account for Linux's coarser thread CPU timer.
