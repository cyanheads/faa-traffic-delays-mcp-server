# 0.2.1 — 2026-10-14

## Changed

- **Airport batches** accept up to 100 submitted codes, validate the entire input before fetching, process 25 distinct airports, and return the canonical `omittedAirports` remainder with `cap`, `processedCount`, and continuation guidance. ([#20](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/20))
- **Advisory discovery** adds literal, case-insensitive `query` matching against subjects and details, combined with category and control-element filters before pagination; `appliedQuery` echoes the trimmed search. ([#22](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/22))
- **NASR directory** refreshes to the 2026-10-01 cycle: 5,274 airports and 2,598 ICAO mappings. Removed identifiers `3L7` and `55G` now return `unknown_airport`; `PAFT` resolves to `FLT`.
- **Packaging and tooling** correct MCP Registry npm launch metadata, exclude first-party sources and docs from MCPB, sync framework skills and checks, align CodeQL categories, and use Bun 1.4.2 → 1.4.3 images with musl-only dependency pruning.

## Fixed

- **Incomplete feeds** disclose unreadable structured sections and skipped pacing rows on both response surfaces, retain usable sibling data, and keep diagnostics scoped to each cached snapshot. ([#15](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/15))
- **Delay profiles** omit and disclose invalid sequence sets instead of shifting interval positions; valid unsorted sequences retain quarter-hour anchors. ([#16](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/16))
- **PHX time zone** corrects only reported `US/Mountain` to `America/Phoenix`, preserving the original value as `reportedTimezone`. ([#17](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/17))
- **Multiline FAA text** escapes Markdown link/image syntax, angle-bracket autolinks, and raw HTML in blockquotes; blockquotes and fences strip controls while preserving lines and identifiers. Clients may still auto-link bare URLs. Structured text stays verbatim. ([#18](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/18))
- **NOTAM** expands to “Notice to Airmen” on both response surfaces. ([#21](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/21))
