# 0.2.0 — 2026-10-02

## Added

- **`faa_delays_list_advisories`** — the ATCSCC advisories issued on one UTC date, newest first: number, control element, subject, further title lines, and ISO 8601 send time per row, including canceled, proposed, and past programs and reroutes. Filters by `categories` or `control_element` (FAA or ICAO airport code, ARTCC, `DCC`), pages with `limit`/`offset` ([#8](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/8)).
- **`programStartTime`** on Ground Delay Program rows of `faa_delays_get_airport_status` and `faa_delays_list_active_events`: when the program began, before any revision. `startTime` is the current revision's arrival window ([#7](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/7)).
- **`artcc`** on every `faa_delays_get_airport_status` row, from the bundled NASR directory, in the form `includedFacilities` lists ARTCCs; an airport the feed does not list now carries the directory's `latitude`/`longitude` ([#9](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/9)).
- **`faa_delays_list_reference`** — topic `artccs` adds ZAP, ZUA, NZZO, ZYZ, and ZVR, so every `artcc` decodes; `terms` adds the advisory-subject vocabulary CDM, CNX, CTOP, and RQD / RMD / PLN / FYI.
- **Public hosted endpoint** — `https://faa-traffic-delays.caseyjhand.com/mcp` (Streamable HTTP), listed in `server.json` `remotes` and the README.

## Changed

- **`feed_contract_changed` recoveries** and the `faa_delays_get_advisory` miss `guidance` point to `faa_delays_list_advisories` for advisory numbers instead of trying sequential numbers.

## Fixed

- **Tool `title`s** are readable Title Case labels (`Get FAA Airport Status`) instead of the snake_case tool name; names are unchanged ([#6](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/6)).
- **`delayProfile.startTime`** is anchored on the feed's `delayTimeAmount`, else the quarter-hour floor of the program start, so a program that began off the quarter hour no longer labels its intervals up to 14 minutes late; AFP profiles share the anchor ([#7](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/7)).
- **`faa_delays_get_advisory`** returns `effectiveTime` and `sentAt` for operations plans and required reroutes, read from the text's last lines when the page has no labelled cell ([#10](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/10)).
- **Fallback delay band** — a decreasing average yields `avg − 15` to `avg − 1` (30 → 15–29), and an average below 15 derives no band while keeping `trend` ([#11](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/11)).
- **Advisory titles** whose control element holds spaces (`EWR AND SATS/ZNY`) return `controlElement` and `subject` ([#12](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/12)).
- **npm package** — the airport directory's `.d.ts` declares `NASR_AIRPORTS_TSV: string` instead of repeating the table as a literal type ([#13](https://github.com/cyanheads/faa-traffic-delays-mcp-server/issues/13)).
- **Advisory cache memory** — cached advisories hold a `structuredClone` of their parsed values, so an entry no longer keeps the fetched page alive.
- **Advisory references** are omitted when the link's `adv_date` names no real calendar day or its `advn` runs into other characters.
