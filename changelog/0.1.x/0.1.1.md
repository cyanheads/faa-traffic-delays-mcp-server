# 0.1.1 — 2026-09-30

## Added

- **`faa_delays_get_airport_status`** — status of 1–25 US airports by FAA identifier or ICAO code: ground stop, Ground Delay Program with its delay profile, arrival and departure delay bands, closures, deicing, and runway configuration with arrival rate. An unknown code fails as `unknown_airport` before any FAA request.
- **`faa_delays_list_active_events`** — every active event nationwide, Airspace Flow Programs included, sorted by severity, with an optional `event_types` filter and per-type counts over the whole feed. An unreadable en-route feed omits Airspace Flow Programs and reports it in `enRouteFeed`.
- **`faa_delays_get_operations_plan`** — terminal and en-route items the Command Center plans for later today, with their planned UTC time and likelihood, plus current ATCSCC announcements and the plan's advisory reference.
- **`faa_delays_get_advisory`** — full text of one ATCSCC advisory by number and UTC date. A number the database does not hold returns `found: false` with guidance; text past 50,000 characters is cut and reported.
- **`faa_delays_list_reference`** — decodes event types, traffic-management terms, ARTCC codes, the FAA pacing airports (read live), and the accepted identifier and time formats.
- **FAA upstream boundary** — `nasstatus.faa.gov/api` and `www.fly.faa.gov/adv` are read keyless, paced per host, retried under a 20 s budget, and cached in process (feeds 60 s; pacing airports and issued advisories 6 h; never served expired). Outages, throttling, and format changes fail with distinct typed reasons.
- **Bundled airport directory** — FAA NASR cycle 2026-09-03 (5,276 US airports, with the ICAO crosswalk) validates airport codes offline; `bun run refresh:airports` regenerates it from the current cycle.
- **Configuration** — no server-specific environment variables; the framework's transport (stdio or Streamable HTTP), auth, and logging variables apply, and HTTP sessions default to `stateless`.
- **Data terms** — FAA status, advisory, and NASR airport data are US federal works in the public domain (17 U.S.C. §105). Informational only, not for flight operations; the NAS Status API is undocumented and can change without notice.
